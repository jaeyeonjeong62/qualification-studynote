**테스트 프로세스에 중대한 영향을 미치는 요소**

1. 소프트웨어 개발수명주기(SDLC)
2. 식별한 제품 리스크
3. 체계적인 화이트 박스 테스팅을 강제하는 새로운 규칙

**테스터에게 가장 중요한 역량**

1. 도메인 지식 보유
2. 좋은 팀 구성원 되기
3. 비판적 사고

**테스트 유형과 애자일 테스팅 사분면**

- 1사분면: 단위 테스팅
- 2사분면: 기능 테스팅
- 3사분면: 사용성 테스팅
- 4사분면: 신뢰성 테스팅

| | 비즈니스 측면 | 기술 측면 |
|---|---|---|
| **팀 지원** | **Q2**<br>• 기능 테스팅<br>• 사용자 스토리 테스팅<br>• API 테스팅 | **Q1**<br>• 단위 테스팅<br>• 컴포넌트 테스팅<br>• 컴포넌트 통합 테스팅 |
| **제품 평가** | **Q3**<br>• 사용성 테스팅<br>• 탐색적 테스팅<br>• 사용자 인수 테스팅 | **Q4**<br>• 성능 테스팅<br>• 보안 테스팅<br>• 부하·스트레스 테스팅 |

**데브옵스의 장점**

1. 빠른 제품 출시 및 짧은 출시 기간
2. 실행 가능한 소프트웨어의 지속적인 가용성

**테스트 대상의 품질 수준을 보고하는 데 많이 사용하는 지표**

1. 시스템 테스팅 중 식별한 결함 수
2. 결함 밀도(식별한 결함 수를 작업 산출물의 크기로 나눈 값)
